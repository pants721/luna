# LUNA (LUcas' N-body Analyzer)
High-performance 3D N-body simulator built in C++20. Implements Barnes-Hut octree and direct summation force solvers with OpenMP and Intel TBB parallelization, symplectic leapfrog integration, and real-time OpenGL rendering.
